Prerequisites & Prework

Prepare yourself for success across the machine learning and cloud AI certification tracks

Are these courses right for you?

Neither the Machine Learning Crash Course nor the cloud AI certification tracks (Azure, AWS, Google Cloud, and Salesforce) assume prior AI experience. To get the most from the lessons and exercises, we recommend meeting the prerequisites below. Not every item applies to every track — treat it as a checklist for the path you choose.

Mathematics

+

Most relevant for the machine learning & data science tracks:

Algebra

  • Variables, coefficients, and functions
  • Linear equations (e.g., y = b + w₁x₁ + w₂x₂)
  • Logarithms and logarithmic equations
  • Sigmoid function

Linear Algebra

  • Tensor and tensor rank
  • Matrix multiplication

Statistics

  • Mean, median, outliers, standard deviation
  • Ability to read histograms

Calculus (Optional)

  • Concept of derivatives
  • Gradient or slope
  • Partial derivatives and chain rule

Programming

  • Working with cloud consoles

Which provider is right for you?

Microsoft Azure

Best if your team already uses Microsoft 365, Azure, or Copilot, and you want AI that plugs into that stack.

AWS

Best for the broadest job market and the widest catalog of AI/ML services, from Bedrock to SageMaker.

Google Cloud

Best for data-heavy and ML-focused roles built around Vertex AI, BigQuery, and Gemini.

Salesforce

Best if you work in CRM, Service, or Sales and want to build and deploy Agentforce AI agents.

Follow the right order

Heads up: codes like AI-901, AI-103, or DP-100 are just exam IDs — a lower number does not mean it comes first. Follow the level order: Foundational → Associate → Professional.

About This Platform

Cloudvana brings together machine learning fundamentals and multi-cloud AI certification prep in one place. Start with a simplified Machine Learning Crash Course based on Google's popular curriculum, then prepare for AI certifications across Microsoft Azure, AWS, Google Cloud, and Salesforce.

Covered certifications include Azure (AI-901, AI-103, DP-100), AWS (AIF-C01, MLA-C01, Generative AI Developer – Professional, MLS-C01), Google Cloud (Generative AI Leader, Professional ML Engineer), and Salesforce (Agentforce Specialist). Every module is self-contained, so you can start with fundamentals or jump straight to the certification track you're targeting.
